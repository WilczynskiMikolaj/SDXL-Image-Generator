# SDXL Image Generator

A work-in-progress **SDXL image generation tool** with  **Gradio-based GUI**.

This project started as an experiment to build **custom SDXL pipelines** for running different checkpoints and configurations.  
Initially, I wanted only terminal usage, but during development I discovered **Gradio**, which made me want to build a GUI.

⚠️ **Project status:**  
The GUI is currently **under construction** due to changes in pipelines design which results in not generating images - Changes stem from the need for more sustainable design to handle other types of pipelines etc. refiner, upscaler, img2img or other txt2img then just simply SDXL
